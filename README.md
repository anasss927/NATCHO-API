# Natcho Script System

نظام حماية سكريبتات بحال Luarmor / Polsec (نسخة بسيطة)

## الصفحات

- `/` — الصفحة الرئيسية
- `/admin` — لوحة الإدارة (توليد كي، حظر، رفع سكريبت، ريست HWID)
- `/panel` — صفحة اليوزر باش ياخد اللودر

## Variables فـ Railway

- `MONGODB_URI` = رابط MongoDB
- `ADMIN_SECRET` = natchoSecret2026

## كيفاش تشغلو

1. رفع الملفات فـ GitHub
2. ربط الريبو مع Railway
3. زيد الـ Variables
4. Generate Domain
